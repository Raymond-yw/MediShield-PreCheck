# MediShield PreCheck - Frontend

Next.js frontend for the MediShield PreCheck application.

## Tech Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS
- Ethers.js v6
- FHEVM RelayerSDK 0.3.0-5

## Development

```bash
pnpm dev
```

## Build

```bash
pnpm build
```
